# Blindrun 

**Blindrun** — это динамичная 2D-игра в жанре психологического хоррора, разработанная на языке C# с использованием графического фреймворка Windows Forms. Проект представляет собой радикальное переосмысление классической игровой механики «Змейка», погружая игрока в атмосферу замкнутого пространства, тьмы и постоянного вызова.

---

## 🎮 Описание игры и правила

Игрок управляет неоново-зеленой сущностью в дискретном пространстве (сетке), окруженном абсолютной темнотой. 

* **Цель игры:** Набрать максимальное количество очков, собирая «Глаза» (элементы сбора), разбросанные по карте.
* **Игровой процесс:** Каждое съеденное око увеличивает длину хвоста змейки. Чем длиннее становится персонаж, тем меньше пространства остается для маневра.
* **Опасности:** На поле расположены статичные красные блоки-стены, а также перемещаются динамические враги (преследователи). Столкновение со стеной, врагом или собственным хвостом приводит к мгновенному окончанию игры (Game Over).

---

## 🕹️ Управление

Игра поддерживает интуитивную и отзывчивую раскладку клавиатуры:

* **Движение:** Клавиши `W`, `A`, `S`, `D` или **Стрелочки** (`↑`, `←`, `↓`, `→`).
* **Пауза:** Клавиша `P` — мгновенно останавливает игровой таймер.
* **Полноэкранный режим:** Клавиша `F11` — для максимального погружения в атмосферу хоррора.
* **Выход в меню:** Клавиша `Esc`.

В игре реализовано стартовое меню с возможностью выбора трёх уровней сложности (**Лёгкий**, **Средний**, **Сложный**), которые изменяют скорость игрового цикла и плотность препятствий.

## 🛠️ Технологический стек и Архитектура

* **Язык программирования:** C#
* **Платформа:** .NET Framework
* **Графический фреймворк:** Windows Forms & GDI+ (`System.Drawing`)

### Архитектурные особенности и паттерны:
1. **Game Loop (Игровой цикл):** Реализован на базе компонента `System.Windows.Forms.Timer`. Все перемещения объектов и обработка состояний привязаны к тикам таймера.
2. **Искусственный интеллект (ИИ) врагов:** В классе `Enemy` реализован кастомный алгоритм случайного патрулирования. Враг выбирает вектор движения из двумерного массива направлений с проверкой коллизий через `HashSet<Point>`. Если на пути ИИ оказывается стена, шаг блокируется, и выбирается новое направление.
3. **Оптимизация рендеринга:** Использование свойства `DoubleBuffered = true` (двойная буферизация) для устранения мерцания графики при обновлении кадров.
4. **Буферизация ввода:** Защита от случайного самопересечения змейки при быстром двойном нажатии клавиш в рамках одного тика таймера.
